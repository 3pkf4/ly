📌 تجربتي مع GitHub Pages

22 يوليو 2025

GitHub Pages تتيح لك نشر مواقع ساكنة (static websites) مجانًا. كل ما تحتاجه هو حساب GitHub، ومجلد فيه ملفات HTML/CSS/JS.

قمت بإنشاء مستودع جديد، أضفت إليه ملف index.html بسيط، وفعلت GitHub Pages من الإعدادات.

الموقع يعمل الآن على رابط مباشر بدون الحاجة لأي استضافة خارجية.

أنصح كل من يريد تجربة بناء موقع بسيط أو مدونة شخصية باستخدام هذه الخدمة.
